# 🕉️ Sanskrit Setu (Sanskrit Learning Hub)

A modern, culturally resonant, and highly interactive React Native mobile application designed to make learning Sanskrit engaging, accessible, and beautiful. Built with a custom "Royal Peacock" dual-theme UI system, leveraging modern design principles like glassmorphism and rich gradients.

---

## ✨ Key Features

The application is structured into four core learning modules:

*   **🔤 Anuvadak (Translator):** A real-time translation interface to seamlessly convert English, Hindi, and Marathi to Sanskrit. Features text-to-speech UI and quick clipboard copying.
*   **📚 Granthalaya (PDF Library):** A curated digital bookshelf for sacred texts, grammar guides, and literature. Features a visually stunning horizontal scrolling grid and recent document tracking.
*   **▶️ Gurukul (Video Lessons):** A masterclass video platform for learning pronunciation, grammar (Vibhakti), and chanting. Features frosted-glass UI elements over video thumbnails.
*   **🎮 Khela (Interactive Games):** A gamified learning module featuring three diverse challenges to test your knowledge: **Picture Identification**, **Sentence Formation**, and **Fill in the Blanks**. Includes real-time score tracking and a premium victory screen to incentivize daily practice.

### 🎨 UI / UX Highlights
*   **Adaptive Dual Themes:** Flawless transition between "Royal Peacock" (Light) and "Midnight Temple" (Dark) modes.
*   **Glassmorphism:** iOS-style blurred bottom tab navigation and frosted video player controls.
*   **Fluid Typography:** High-contrast, highly legible typography designed for both Devanagari script and English.
